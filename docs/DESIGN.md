# Интерфейс StatsMeister: правила

Для кого: обычный симрейсер, который хочет после заезда понять, где он теряет время и что сделать иначе. Не инженер команды. Всё, что нужно инженеру, остаётся доступно, но не на первом экране.

## Структура

- **Слева** запись, импорт реплея и список сессий по дням. Больше ничего.
- **Сессия** открывается на вкладке «Разбор». Она отвечает на три вопроса по порядку:
  1. Как прошло: одна-две фразы с лучшим кругом, потенциалом и рекордом.
  2. Где уходит время: до четырёх поворотов, у каждого совет простыми словами. По клику раскрываются три коротких графика только этого поворота.
  3. Круги: время, отставание от лучшего, полоска для наглядности. Клик по кругу сравнивает его с лучшим.
- **«Графики»** для тех, кто хочет копнуть: все каналы, таблица поворотов, потенциал по отрезкам, значения под курсором.
- **«Прогресс»** показывает историю трассы и машины: короткий вывод, график, таблица сессий.

Новый элемент сначала попадает в «Графики». На «Разбор» он переезжает только тогда, когда отвечает на один из трёх вопросов выше.

## Язык

- Пишем фразами, а не наборами метрик: «Лучший круг 1:50.810 (круг 4)», а не «BEST 1:50.810».
- Никакого A/B в основном интерфейсе: «лучший круг», «круг 5», «рекорд от 12 октября».
- Обращаемся на «вы». Без маркетинговых слов, без восклицаний, без длинных тире в каждой фразе.
- Числа с той точностью, которая что-то значит: метры целыми, км/ч до десятых, потери до сотых.

## Визуал

- Палитра нейтральная графитовая (`--bg`, `--surface`, `--line`). Без синевы, неона и градиентов.
- Один акцент `--accent` (янтарный) обозначает сравниваемый круг. Лучший круг на графиках нейтральный светлый.
- Цвета времени как в мотоспорте: фиолетовый `--best` для лучших времён, зелёный `--gain` для выигрыша, красный `--loss` для потери. Ни для чего другого.
- Шрифт системный: Segoe UI Variable. Для чисел `tabular-nums`, моноширинный не используем.
- Иерархию строят размер и жирность текста и отступы, а не рамки. Карточки и рамки только у того, что действительно отдельный объект: кнопки, поля, всплывающие сообщения.

### Чего не делать

Эти приёмы сразу выдают «сгенерированный» интерфейс:

- градиенты (особенно фиолетово-синие и цианово-розовые), градиентный текст и логотип;
- свечение, glassmorphism, размытые подложки;
- карточки с цветной полосой сбоку, карточки внутри карточек, одинаковые сетки карточек;
- подписи капсом с разрядкой над каждым блоком;
- раскладка «большое число и маленькая подпись» для каждой метрики;
- цветные точки и бейджи без смысла, пульсирующие индикаторы;
- эмодзи вместо иконок;
- огромные скругления, «тонкая рамка плюс широкая тень».

## Проверка перед изменением UI

- Контраст текста не ниже 4.5:1. Самый тусклый текст `--text-3` на фоне `--bg` даёт около 5.5:1.
- У всех интерактивных элементов виден фокус (`:focus-visible`), это настоящие `button`, `select` или строки с обработчиком.
- Нет горизонтальной прокрутки при ширине окна от 1000 px; ниже 1100 px колонки встают друг под друга.
- Все строки есть в `app/src/i18n.ts` на русском и английском.
